# Transactions API

## Transactions API

## Returns the list of transactions by a specific time period.

<mark style="color:green;">`POST`</mark> `https://<WooApi_site>/transaction/list`&#x20;

The game operator can retrieve a list of transaction history by searching based on the transaction settlement time.

**Bet Status definition:**&#x20;

`0` = Unsettled Bet

`1` = Settled Bet

`2` = Cancelled Bet

`3` = Refunded Bet

#### Headers

| Name                                           | Type   | Description                                                                                                               |
| ---------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------- |
| Content-Type<mark style="color:red;">\*</mark> | String | application/json                                                                                                          |
| X-API-Key<mark style="color:red;">\*</mark>    | String | Operator's API key                                                                                                        |
| X-Signature<mark style="color:red;">\*</mark>  | String | A digital signature generated using HMAC-SHA256 algorithm signed using the operator's API secret key on the request body. |

#### Request Body

| Name                                       | Type    | Description                                                                                     |
| ------------------------------------------ | ------- | ----------------------------------------------------------------------------------------------- |
| traceId<mark style="color:red;">\*</mark>  | String  | A Universally Unique Identifier (UUID) generated by the Operator's system for each API request. |
| fromTime<mark style="color:red;">\*</mark> | Long    | The timestamp to retrieve transactions from.                                                    |
| toTime<mark style="color:red;">\*</mark>   | Long    | To retrieve transactions up to this timestamp.                                                  |
| pageNo<mark style="color:red;">\*</mark>   | Integer | Page number.                                                                                    |
| pageSize                                   | Integer | Page size. Default: 2000, Max: 5000                                                             |

## Retrieve Detailed Transaction Info for a Specific Bet Transaction&#x20;

<mark style="color:green;">`POST`</mark> `https://<WooApi_site>/v2/transaction/detail`

This API allows the game operator to retrieve a single transaction's detailed history by searching with the `betId` and specifying a time range using the `fromTime` and `toTime` parameters (both in UNIX Timestamp format).

The time range between `fromTime` and `toTime` must be within 7 days. If the range exceeds 7 days, the query will fail, and no data will be returned.

**Bet Status definition**:&#x20;

`0` = Unsettled Bet

`1` = Settled Bet

`2` = Cancelled Bet

`3` = Refunded Bet

#### Headers

| Name                                           | Type   | Description                                                                                                               |
| ---------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------- |
| Content-Type<mark style="color:red;">\*</mark> | String | application/json                                                                                                          |
| X-API-Key<mark style="color:red;">\*</mark>    | String | Operator's API key                                                                                                        |
| X-Signature<mark style="color:red;">\*</mark>  | String | A digital signature generated using HMAC-SHA256 algorithm signed using the operator's API secret key on the request body. |

#### Request Body

| Name                                       | Type   | Description                                                                                     |
| ------------------------------------------ | ------ | ----------------------------------------------------------------------------------------------- |
| traceId<mark style="color:red;">\*</mark>  | String | A Universally Unique Identifier (UUID) generated by the Operator's system for each API request. |
| betId<mark style="color:red;">\*</mark>    | String | The unique Id that identifies this bet request transaction                                      |
| fromTime<mark style="color:red;">\*</mark> | Long   | The starting time for the query, in UNIX Timestamp (milliseconds).                              |
| toTime<mark style="color:red;">\*</mark>   | Long   | The ending time for the query, in UNIX Timestamp (milliseconds).                                |
| displayLanguage                            | String | The language code for localised Game Vendor bet detail Url translation                          |
