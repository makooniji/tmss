# Transfer Wallet API

Single Transfer Wallet Endpoint

## Request to deposit funds into a player's wallet by specifying the username, amount, and currency.

<mark style="color:green;">`POST`</mark> `https://<wooapi_site>/gateway/cash/deposit`

The OneAPI system enforces idempotency across all API operations. Operators MUST resend the request using the SAME `referenceId` under the following error scenarios:

*SC\_MISMATCHED\_DATA\_TYPE, SC\_INVALID\_REQUEST, SC\_AUTHENTICATION\_FAILED, SC\_INVALID\_SIGNATURE, SC\_WRONG\_CURRENCY, SC\_CURRENCY\_NOT\_SUPPORTED*

<mark style="color:red;">**IMPORTANT**</mark>: `referenceId` is a unique identifier for each transaction. Operators must generate a new `referenceId` for every new transfer request.

Before considering resending a transfer request, operators are strongly advised to verify the transaction status using the '`/cash/getsingletransaction`' endpoint to handle other potential failure scenarios.

#### Headers

| Name | Type | Description |
| --- | --- | --- |
| Content-Type<mark style="color:red;">\*</mark> | String | application/json |
| X-Signature<mark style="color:red;">\*</mark> | String | Digital signature generated using the HMAC-SHA256 algorithm by signing the request body with the operator's API Secret Key. |
| X-API-Key<mark style="color:red;">\*</mark> | String | Operator's API Key |

#### Request Body

| Name | Type | Description |
| --- | --- | --- |
| username<mark style="color:red;">\*</mark> | String | Username of the player in the operator's system |
| traceId<mark style="color:red;">\*</mark> | String | Universally Unique Identifier (UUID) generated by the operator's system for each API request. |
| transferAmount<mark style="color:red;">\*</mark> | String | Transfer amount (up to 8 decimal places, minimum 0.00000001) |
| currency<mark style="color:red;">\*</mark> | String | Player's currency. ISO-4217 currency code (e.g., USD) |
| referenceId<mark style="color:red;">\*</mark> | String | Universally Unique Identifier (UUID) generated by the operator's system for each API request. |
